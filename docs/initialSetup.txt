 INITIAL SETUP — OSIRIS COMMUNITY NODE
=====================================

Project:
--------
Minimal decentralized neighborhood communication network using:

- Raspberry Pi
- Reticulum
- NomadNet
- Off-Grid-Community-Suite
- Local WiFi
- Optional captive portal
- Optional internet mirror

Goal:
-----
Create a portable community communication node that works:
- locally without internet
- over Reticulum
- through NomadNet
- via local WiFi
- optionally with normal web browsers

Architecture:
-------------
Windows / Android / Linux Clients
                ↓
         TCP Reticulum
                ↓
      Raspberry Pi "Osiris"
                ↓
     NomadNet Community Suite
                ↓
   Blog / Chat / Forum / Yellow


========================================================
PHASE 1 — RASPBERRY PI BASE INSTALL
========================================================

Hardware:
---------
- Raspberry Pi 3B
- Ethernet or WiFi
- microSD card
- Power supply

Recommended OS:
---------------
Raspberry Pi OS Lite

Hostname:
---------
osiris

Set hostname:

sudo raspi-config


========================================================
PHASE 2 — SYSTEM UPDATE
========================================================

sudo apt update
sudo apt upgrade -y


========================================================
PHASE 3 — PYTHON VENV
========================================================

New Raspberry Pi OS versions block system-wide pip installs.

Install:

sudo apt install python3-venv python3-full python3-pip git -y

Create venv:

python3 -m venv ~/rns-venv

Activate:

source ~/rns-venv/bin/activate


========================================================
PHASE 4 — INSTALL RETICULUM
========================================================

Inside venv:

pip install --upgrade pip
pip install rns

Generate config:

rnsd --exampleconfig

Config location:

~/.reticulum/config


========================================================
PHASE 5 — ENABLE TCP SERVER
========================================================

Edit:

nano ~/.reticulum/config

Add as top-level interface block:

[[AutoInterface LAN]]
    type = AutoInterface
    interface_enabled = True

[[TCP Server]]
  type = TCPServerInterface
  enabled = yes
   listen_ip = 0.0.0.0
   listen_port = 4242

[[Berlin_IPv4]]
  type = BackboneInterface
  enabled = yes
  remote = 82.165.27.170
  target_port = 443
  transport_identity = 226849a1caffd1f15946a51768f3366e



when adding BackboneInterface be aware that for instance ipv6 
host addresses might not work depeding on the network setup

PHASE 6 — START RETICULUM

Start:

source ~/rns-venv/bin/activate

========================================================
PHASE 16 — setup service to start rnsd on startup of osiris
========================================================



sudo nano /etc/systemd/system/rnsd.service

[Unit]
Description=Reticulum Transport Node Daemon
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=osiris
WorkingDirectory=/home/osiris
ExecStart=/home/osiris/rns-venv/bin/rnsd
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target


stop and start reticulum-startup.service
    sudo systemctl stop reticulum-startup.service
    systemctl status reticulum-startup.service

    sudo systemctl daemon-reload
    sudo systemctl enable --now reticulum-startup.service
    systemctl status reticulum-startup.service
    journalctl -u reticulum-startup.service -f



sudo systemctl enable --now rnsd


========================================================
PHASE 17 — install tmux in order to have nomadnet running
========================================================

We install the utility tmux so that we can start a detached terminal session
in this we will start nomadnet. This enables us to connect via ssh to 
osiris and then via tmux to an nomadnet instance which is allways running

sudo apt install tmux

tmux new -s nomadnet


to leave the tmux session without closing it [Ctrl] + [B] and then [D]

to reconnect to the session 
tmux attach -t nomadnet


tmux ls

tmux kill-session -t nomadnet



========================================================
PHASE 17b — put the tmux setup in a service so that it starts on boot
========================================================

nano ~/.config/systemd/user/nomadnet-tmux.service

[Unit]
Description=NomadNet inside tmux
After=network-online.target

[Service]
Type=oneshot
RemainAfterExit=yes
ExecStart=/usr/bin/tmux new-session -d -s nomadnet 'nomadnet'
ExecStop=/usr/bin/tmux kill-session -t nomadnet

[Install]
WantedBy=default.target


systemctl --user daemon-reload
systemctl --user enable --now nomadnet-tmux
loginctl enable-linger $USER
